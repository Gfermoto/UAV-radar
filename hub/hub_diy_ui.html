Облако

Токен Cloud (LoRa) — только для пакетов, которые Hub форвардит из MQTT в облако. DIY/Light несут свой Bearer в PB; сюда он не подставляется. Пока Cloud недоступен, события ждут в буфере.

Адрес Cloud (origin) — в инженерном меню (клик по версии). MQTT в Cloud не уходит.

Площадки и небо

Площадка — круг на карте, обычно 8–15 км. Свежие координаты устройства важнее центра круга. Если в круге гражданский самолёт, события этой площадки можно не отправлять в облако.
