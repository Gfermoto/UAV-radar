NEVOD DIY v0.19.0-ota

Подписанный бинарник для USB-прошивки (XIAO ESP32-S3 + Seeed XVF3800). Тихий БПЛА, стрелка поиска, кольцо по азимуту.

Что нового

  • Тихий БПЛА: слушающий луч наводится при более низком RMS, без ожидания громкой комнаты.
  • Стрелка: тонкая стрелка поиска видна всегда; толстая — только в захвате.
  • Кольцо: совпадает с азимутом стрелки (разворот +180°).
  • nevod commit 9401bee9.
