NEVOD DIY v0.15.0-ota

Подписанный бинарник для USB-прошивки (XIAO ESP32-S3 + XVF3800).

Что нового

  • Anti-FP gate: mel_contrast_min_db снова режет publish DET и Mel после NN confirm, если LAeq contrast ниже порога (на шумных площадках — меньше ложных срабатываний).
  • В WebUI / /status: phase=energy_gated, energy_gated=true.
  • Порог настраивается per-site (NVS mel_cmin); 0 = gate выключен.
  • OTA: устройства на канале diy-ota подтягивают semver автоматически.
  • Первый вход: admin / nevod-change-me — смените пароль сразу.
