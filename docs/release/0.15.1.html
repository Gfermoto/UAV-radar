NEVOD DIY v0.15.1-ota

Подписанный бинарник для USB-прошивки (XIAO ESP32-S3 + XVF3800).

Что нового

  • Evidence confirm: класс подтверждается только на новом TFLite infer — повторный poll того же inferCount не даёт confirm (stale_infer).
  • Lab Mel: синтетический lab_ping только в полном idle (нет episode / current evidence).
  • Telemetry: public locator включает energy_gated и confirm_block_reason; сняты legacy detection_*_min из NVS/API.
  • Из 0.15.0: mel_contrast_min_db режет DET/Mel после NN confirm при низком LAeq contrast.
  • OTA: устройства на канале diy-ota подтягивают semver автоматически.
  • Первый вход: admin / nevod-change-me — смените пароль сразу.
