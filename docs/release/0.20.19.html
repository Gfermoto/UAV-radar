NEVOD DIY v0.20.19-ota

Подписанный бинарник для USB-прошивки (XIAO ESP32-S3 + Seeed XVF3800).

Полный список — CHANGELOG 0.20.18–0.20.19. Прошивка в лаборатории: только safe_upload.py, без стирания NVS.

Что нового

  • Ложный jet на Light Eth. Пока SPI Ethernet глушил пеленг, живой XVF больше не считается «массива нет»: jet не подтверждается по одному таймауту.
  • Пеленг в статусе. detection.src_doa_available всегда показывает, доступен ли DoA.
  • SPI Ethernet 16 МГц. Дефолт частоты W5500 поднят с 4 до 16 МГц; в /status видны eth_spi_hz и счётчики I2C XVF.
