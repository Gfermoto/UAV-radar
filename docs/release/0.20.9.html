NEVOD DIY v0.20.9-ota

Подписанный бинарник для USB-прошивки (XIAO ESP32-S3 + Seeed XVF3800).

Что нового

  • Диагностика: новый GET /api/system/coredump показывает причину последнего падения (задача, адрес, backtrace) без UART. INT_WDT и panic не пишут NVS, теперь причину сброса видно из WebUI.
  • Сборка: воспроизводимая — bin релиза побайтно совпадает с локальной сборкой тега.
  • Гейт надёжности: WDT до старта проверки больше не валит релиз, а остаётся предупреждением.
  • Содержит изменения 0.20.8 (free_heap_min_mode в /status), который в канал не выходил.
