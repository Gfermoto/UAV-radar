NEVOD DIY v0.20.17-ota

Подписанный бинарник для USB-прошивки (XIAO ESP32-S3 + Seeed XVF3800).

Что нового

  • Меньше ложных тревог в тишине. Авто-порог контраста LAeq (режим по умолчанию) — узел сам учит разброс фона и ставит порог; сохраняется в NVS и действует сразу после перезагрузки; до обучения фона публикация без тона винта удерживается (до 90 с). Ручной режим остался, 0 = гейт выкл (сбор данных).
  • Гейт ТРД-БПЛА: jet больше не подтверждается по одному таймауту, если пеленг XVF доступен.
  • Надёжность: настройки сети сохраняются единым путём (правки WebUI/MQTT/LED не затирают друг друга); ошибки записи NVS видны (system.nvs_save_pending); устранены гонки кэша паролей, буфера CA и статуса CA.
  • Безопасность: загрузку OTA/модели может продолжить только её инициатор; во время блокировки входа верный пароль тоже получает 429; GitHub-токен не уходит при редиректе; JSON из нескольких TCP-пакетов принимается.
  • WebUI: одинаковое инженерное меню на DIY и Light; переключатель Авто/Ручной для порога контраста.
