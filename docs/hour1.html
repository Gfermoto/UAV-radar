NEVOD

За час: узел живой

Плата прошита, слышит хлопок, пеленг на экране. MQTT, корпус и облако — потом.

  1. 1. Прошивка

    Chrome или Edge, USB‑C в модуль XIAO (не у разъёма 3.5 mm). Install → порт. Erase по умолчанию снят; галочка ок, если COM не моргает. После 100% сразу закройте окно. Если COM моргает — выньте USB на секунду.

    После 100% закройте окно. Не оставляйте вкладку с открытым портом. Телефон — скачайте файл.

    Скачать .bin · esptool.spacehuhn.com · адрес 0x0

  2. 2. Wi‑Fi

    Подключитесь к точке NV… (пароль = SSID, ЗАГЛАВНЫЕ). Откройте http://192.168.4.1, укажите домашнюю сеть 2.4 ГГц. После — войдите в WebUI (admin / nevod-change-me) и сразу смените пароль.

  3. 3. Проверка

    Хлопните рядом с микрофонами — уровень и азимут в WebUI должны дёрнуться.

  4. DSP 1.0.8 (желательно)

    Для стабильнее азимута прошейте чип XVF3800 образом Seeed I²S slave 1.0.8 / 16 kHz (разъём у 3.5 mm, DFU Upgrade, не Factory). Пропуск — только если чип уже 1.0.8. . Иначе — полный гайд §1.

Дальше — калибровка, корпус, MQTT / HA и облако в полной инструкции.
