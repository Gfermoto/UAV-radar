Прошить DSP

Микрофонный чип XVF3800 → Seeed I²S slave 1.0.8. Это не прошивка ESP на XIAO.

  1. 1. Разъём

    USB‑CЗачем
    У гнезда 3.5 mm (сторона XVF)Эта страница — DSP
    На модуле XIAOESP — лендинг / «за час»

    Кабель с данными. Вставляйте только у 3.5 mm.

  2. 2. Режим DFU (всегда так)

    Mute и Reset на ReSpeaker — на противоположных краях платы.

    1. Зажмите Mute.
    2. Не отпуская Mute — коротко нажмите Reset.
    3. Mute мигает, кольцо гаснет → готово.

  3. 3. Windows — WinUSB

    Если браузер не видит устройство: Zadig → Options → List All Devices → reSpeaker / XVF3800 → драйвер WinUSB. macOS / Linux обычно без Zadig.

  4. 4. Прошить

    Chrome или Edge. Только слот Upgrade (не Factory). Образ I²S slave 16 kHz v1.0.8 — не master 48 kHz.

    После TIMEOUT не жмите сразу снова: выньте USB ~10 с, снова Mute+Reset, одна попытка.

    Если видели «Wrote … bytes» / «Manifesting», а потом ошибка reset — образ уже записан: выньте USB у 3.5 mm на ~5 с. Не прошивайте повторно.

    Скачать .bin · SHA-256 9dc3308a…f2d99eb8

  5. 5. Без браузера

    Тот же образ через dfu-util (после Mute+Reset):

    dfu-util -d 2886:001a -t 4096 -a 1 -D application_xvf3800_i2s_slave_v1.0.8_16k.bin

Дальше — прошивка ESP на лендинге или за час. Полный путь: гайд.
