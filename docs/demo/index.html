Базовые настройки

Выкл — фиксирует профиль детекции.

Аппаратный срез на чипе: выкл / 70 / 125 / 150 / 180 Гц. По умолчанию 125 Гц (desk). Тот же срез — нижняя граница тонального анализа на ESP. После Apply смотри hpf_readback.

Минус 1° за каждые полные 10 м высоты установки. Может уйти ниже горизонта.

+15° к лучу только при захвате цели (DET/hold). В LISTEN база и DoA/BF работают, доп. завышение — нет.

Включено — луч держит азимут и завышение, в том числе после перезагрузки.

Без галочки удержание ползунка держит луч около 3 с.

0° платы = север. Нестандартный монтаж сохраните здесь; луч и кольцо не поворачиваются.

Авто-порог сейчас—

Насколько звук должен выделяться на фоне, чтобы событие ушло в отчёт. Ниже порога слушает, но не публикует. Авто: учит порог по тишине (p95+1 дБ), ползунок = нижняя граница (0 → 3 дБ по умолчанию), потолок 6 дБ. Ручной: порог = ползунок, 0 = публиковать всегда. Пол для jet без tonal — Инженерное → Гейт ТРД. Тональный винт не блокируется.

Контраст LAeq сейчас—

Desk baseline (колонка≠поле): gain 8, AGC выкл, HPF 125 Гц, NS выкл. Точка отсчёта, не полевой оптимум.

Калибровка микрофона

SPL при 0 dBFS по эталонному шумомеру (60…160 дБ, SPL = dBFS + офсет). 0 = не откалибровано: заводской номинал 121 дБ (REW+UMIK) со звёздочкой.

Локальная сеть (LAN)

Команды из Home Assistant или с сервера принимаются только с подписью. Ключ создаётся автоматически из адреса устройства — вводить ничего не нужно. Выключите, если команды должны приниматься без подписи. Не защищает от того, у кого есть физический доступ к устройству.

Обычно 1883 — можно указать любой порт вашего брокера.

Телеметрия в Home Assistant или в локальный брокер в доверённой сети (LAN/VPN). Шифрование MQTT на узле не используется.

Площадка

На площадке один локальный сервер: либо Hub, либо FOG (не оба). Это разные продукты, друг друга не вызывают. В DETECT DIY/Light шлют события и пульс на него; нет ответа — fallback в облако. И Hub, и FOG принимают пакеты и могут буферизовать/пересылать в облако (у каждого свой пульт). Живой звук (RTSP) забирает только FOG. В поле — HTTPS-приём protobuf, не URL пульта: Hub «IP:9444» (пример 192.168.1.130:9444); FOG «IP:9443» (пример 192.168.1.118:9443). Пульт FOG :8090 и HTTP :8088 (CA) сюда не писать.

Связь с локальным сервером—

Cloud (HTTPS)

Вставьте только hex/строку токена (без слова Bearer) и Сохранить. Плата подтянет CA и проверит Cloud.

Связь с Cloud—

NTP

Primary NTP. Fallback: time.google.com, time.cloudflare.com.
