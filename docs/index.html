Что получает узел

Микрофонный массив слышит пропеллер и ДВС, плата классифицирует звук локально и показывает направление.

  • Распознавание на плате — INT8-модель прямо на ESP32-S3, без отправки аудио «куда-то»
  • Пеленг и спектр — азимут, угроза, MEL в живом WebUI
  • Home Assistant — MQTT Auto Discovery: сущности появляются сами
  • Две прошивки на одном железе — NEVOD DIY (датчик) или открытый RTSP Mic (сад / BirdNET)

Два пути одного узла

Сначала — свой двор. Народный радар — когда готовы включить узел в общую сеть раннего оповещения.

Локально

Двор и Home Assistant

Прошейте, настройте Wi‑Fi, подключите MQTT / HA. Алерты у вас дома. Облако NEVOD не обязательно.

Сеть

Народный радар

Токен из кабинета и координаты установки — узел входит в общую сеть раннего оповещения. Больше людей получают шанс среагировать. Облако не публикует координаты нод; владельцам нод — преференции от сервиса.

Почему это DePIN

Распределённая акустическая сеть: узлы у людей дома, не в чужом дата‑центре.

  • Железо ваше — купили, собрали, повесили. Двор не отключают по подписке
  • Локально по умолчанию — детекция на ESP32-S3; MQTT / HA без облака NEVOD
  • Сеть — opt-in — токен и координаты; позиции нод облако не публикует
  • Плотность = сила — каждый новый узел закрывает слепую зону для сети

Смета ядра ≈ ₽9 800. Один узел — один сектор. Соседи и второй угол — меньше слепых зон.

Как собрать

  1. Закажите детали по смете и распечатайте корпус
  2. Прошейте чип и XIAO по полной инструкции DIY — подписанный .bin
  3. Wi‑Fi через точку NV… (пароль = SSID, ЗАГЛАВНЫМИ), смените пароль WebUI. Для двора — MQTT / Home Assistant
  4. Для народного радара: свой Cloud‑токен из кабинета и координаты + высота
  5. Соберите корпус и повесьте узел (виброразвязка ¼″, USB на Юг) — шаги и фото в той же инструкции

Один комплект железа — два образа прошивки: датчик NEVOD или открытый RTSP Mic. Не смешивайте .bin.

Один узел закрывает сектор двора. Второй — другой угол или соседний участок: меньше слепых зон.

Что открыто, что закрыто

Честная модель DIY / DePIN: открытое железо и mic, подписанный датчик.

  • Открыто (MIT) — прошивка RTSP Mic, WebUI API, BOM, STL корпуса, эта инструкция
  • Закрыто — веса и логика детекции БПЛА внутри подписанного nevod-diy-*.bin
  • Проверка — sha256 в manifest.json релиза; подпись .sig рядом с бинарником
  • Облако — opt-in; не публикует координаты нод; владельцам нод — преференции
