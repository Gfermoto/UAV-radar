Базовые настройки

Вкл — слышит слабый сигнал дальше. Выкл — стабильнее спектр MEL / запись.

Без динамика: эхо и AEC residuals выкл, поля серые. Вкл — настройка под монитор.

Аппаратный срез на чипе: выкл / 70 / 125 / 150 / 180 Гц. Не «мягкий/жёсткий» — дискретная команда. После Apply в ответе API смотри hpf_readback.

Запись: beamforming. Монитор/динамик: AEC residuals.

Калибровка микрофона

Офсет по эталонному шумомеру (−40…+40 дБ). Если не хватает — снизьте чувствительность микрофона.

Инженерная панель DSP

ВНИМАНИЕ: изменение этих параметров может ухудшить качество звука. Меняйте только если понимаете последствия.

Noise Suppression (подавление шума)

1.00 = выкл (прозрачно). Меньше = сильнее давит. 0 = максимум (режет тоны птица!).

Параметры AGC

Limiter (ограничитель выхода)

Времена AGC

Ослабление в тишине / AEC

Ослабление в тишине снижает AGC на фоне. Ref/Delay — калибровка AEC под динамик.

Выкл / Вкл: доп. снижение AGC в тишине (меньше фона при высоком усилении).

Базовое доп. ослабление в тишине при номинальном уровне. 1.0 = по умолчанию DSP.

Консервативно ~0.2: почти не давит высокий AGC (дальность). 1.0 ≈ фон стабилен независимо от AGC. >1 — жёстче.

Усиление опорного сигнала AEC (путь к динамику). Компенсирует потери DSP. Не влияет на звук из динамика.

Сдвиг AEC между reference и микрофонами. Отрицательные — для каузальности DSP (~≤40 сэмплов). 0 = без сдвига.

Линейное усиление выхода beamforming на I2S (только если ASROUT = лучи). Диапазон 0…1000.
